# IHSB STEM FEST — Concept Website Demo

A frontend-only concept redesign built in Next.js for internal review.

## Run locally
1. Install Node.js 18+
2. Open this folder in a terminal
3. `npm install`
4. `npm run dev`
5. Open http://localhost:3000

## Publish free on Vercel
### Easiest method
1. Create a new GitHub repository.
2. Upload all files from this folder (not the ZIP itself).
3. Sign in to Vercel with GitHub.
4. Click **Add New → Project**.
5. Import the repository.
6. Framework should be detected as **Next.js**.
7. Click **Deploy**.

Vercel will provide a free `*.vercel.app` URL.

## Important
This is a concept demo, not the live IHSB STEM FEST site. Registration and login are intentionally non-functional. Dates and final 2027 content should be approved before production use.
